# Project Setup

## Prerequisites

Install the following software before starting development:

* Node.js 22 LTS or later
* npm
* Git
* Visual Studio Code

Recommended VS Code Extensions:

* ESLint
* Prettier
* Tailwind CSS IntelliSense
* Error Lens
* GitLens
* Path IntelliSense

---

# Clone Repository

```bash
git clone <repository-url>

cd mark-estrella-real-estate
```

---

# Install Dependencies

```bash
npm install
```

---

# Create Environment Variables

Create

```text
.env.local
```

Example

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000

NEXT_PUBLIC_FB_PAGE=

NEXT_PUBLIC_GOOGLE_MAP=

NEXT_PUBLIC_EMAIL=
```

---

# Install shadcn/ui

```bash
npx shadcn@latest init
```

Preset

* Vega

Base Color

* Slate

CSS Variables

* Yes

---

# Install Packages

```bash
npm install framer-motion

npm install swiper

npm install aos

npm install react-hook-form

npm install zod

npm install @hookform/resolvers

npm install lucide-react

npm install clsx tailwind-merge

npm install next-sitemap
```

---

# Start Development

```bash
npm run dev
```

Application

```
http://localhost:3000
```
