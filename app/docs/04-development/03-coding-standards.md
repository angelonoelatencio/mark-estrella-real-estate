# Coding Standards

## General

* Use TypeScript.
* Prefer Server Components.
* Use Client Components only when required.
* Keep components reusable.

---

## Naming

### Components

```text
Hero.tsx

Navbar.tsx

PropertyCard.tsx
```

---

### Hooks

```text
useScroll.ts

useProperties.ts
```

---

### Types

```text
property.ts

company.ts
```

---

### Constants

```text
routes.ts

colors.ts
```

---

## File Rules

One component per file.

Avoid files exceeding 300 lines where practical.

Separate UI from business logic.

---

## Commits

```text
feat:

fix:

refactor:

style:

docs:

test:
```

Example

```text
feat: add property gallery

fix: resolve mobile navigation overflow

docs: update project setup
```
