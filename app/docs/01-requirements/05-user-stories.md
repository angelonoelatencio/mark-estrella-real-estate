# User Stories

## Visitor

### US-001

As a visitor,

I want to know who Mark Estrella is,

so that I can trust the agent.

---

### US-002

As a visitor,

I want to browse available properties,

so that I can find a suitable home.

---

### US-003

As a visitor,

I want detailed property information,

so that I can make informed decisions.

---

### US-004

As a visitor,

I want to send inquiries,

so that I can communicate with the agent.

---

### US-005

As a visitor,

I want Facebook Messenger support,

so that I can receive faster responses.

---

### US-006

As a visitor,

I want the website to work on my mobile phone,

so that I can browse anywhere.

---

## Website Owner

### US-007

As the website owner,

I want to add more property projects,

so that I don't need to rebuild the website.

---

### US-008

As the website owner,

I want future scalability,

so that the website grows with my business.

---

### US-009

As the website owner,

I want customers to contact me easily,

so that I can generate more sales leads.

---

## Acceptance Criteria

* Users can browse properties.
* Users can view property pages.
* Users can contact the agent.
* Messenger is accessible.
* Website is responsive.
* Property pages are dynamically generated.
