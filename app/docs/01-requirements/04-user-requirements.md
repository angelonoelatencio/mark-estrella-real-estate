# User Requirements

## Visitor

The visitor should be able to:

* View the homepage
* Learn about Mark Estrella
* View company information
* Browse available properties
* View property details
* Contact the agent
* Chat using Facebook Messenger
* Access the website using mobile devices

---

## Website Owner

The website owner should be able to:

* Add future property projects
* Update property information
* Receive customer inquiries
* Promote new projects
* Build credibility online

---

## Performance Requirements

The website should:

* Load quickly
* Be responsive
* Be secure
* Be available 24/7
