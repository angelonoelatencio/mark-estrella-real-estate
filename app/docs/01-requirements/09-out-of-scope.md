# Out of Scope

The following features are not included in Phase 1:

* Admin Dashboard
* Content Management System (CMS)
* Property Management Portal
* Customer Login
* User Registration
* Online Reservation
* Payment Gateway
* Mortgage Calculator
* Property Comparison
* Customer Favorites
* Appointment Scheduling
* Email Marketing Automation
* CRM Integration
* AI-powered Chatbot
* Multi-language Support
* Native Mobile Application

These features are planned for future phases as the client's business grows.
