# Folder Structure

```text
src/
│
├── app/
├── components/
│   ├── common/
│   ├── layout/
│   ├── home/
│   ├── about/
│   ├── company/
│   ├── properties/
│   ├── contact/
│   └── chatbot/
│
├── data/
├── hooks/
├── lib/
├── services/
├── constants/
├── types/
├── utils/
├── styles/
└── assets/
```

Each folder has a single responsibility.

Avoid placing business logic inside UI components.
